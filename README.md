# ⚔️ RPG Manager

Projeto pessoal para criação e gerenciamento de fichas de personagens de RPG, com foco inicial em **Dungeons & Dragons 5ª Edição (D&D 5e)**.

O RPG Manager está sendo desenvolvido como um projeto de estudo, com o objetivo de praticar programação e, futuramente, facilitar a criação, organização e gerenciamento de personagens de RPG de mesa.

## 🎯 Objetivos

* Criar fichas de personagens de RPG de forma prática e organizada.
* Desenvolver uma interface intuitiva e visualmente inspirada em fantasia medieval.
* Implementar cálculos automáticos para atributos e estatísticas dos personagens.
* Permitir salvar e gerenciar fichas de personagens.
* Aprimorar minhas habilidades de programação por meio de um projeto prático.

## 🛠️ Tecnologias

* **HTML5:** estrutura e organização dos elementos da ficha.
* **CSS3:** estilização, layout e responsividade da interface.
* **JavaScript:** planejado para implementar interatividade e cálculos automáticos.
* **Git e GitHub:** controle de versão e hospedagem do código-fonte.

## 🚧 Estado atual do projeto

O projeto está em desenvolvimento.

Atualmente, o foco está na construção da estrutura HTML e na estilização da interface, incluindo os campos de identificação do personagem, atributos e informações de combate.

* [x] Estrutura inicial da ficha de personagem.
* [x] Campos para nome, raça, classe e nível.

### Funcionalidades planejadas

* [ ] Cálculo automático dos modificadores de atributos.
* [ ] Cálculo automático da iniciativa e de outras estatísticas.

## ▶️ Como executar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.
4. Para editar o projeto, utilize um editor de código, como o Visual Studio Code.

Como o projeto está em desenvolvimento, algumas funcionalidades planejadas ainda não estão disponíveis.
